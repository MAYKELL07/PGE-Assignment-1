Project notes

Open Emberfall.unity in the Scenes folder and press Play to run the game.
PhysicsLab.unity is the separate physics demo.

The main README at the project root has the controls and setup instructions.

Files in this folder:
- TechnicalReportDraft.md: short report outline to finish with screenshots and personal notes.
- AssessmentEvidence.md: where to find the physics examples.
- DemoVideoShotList.md: a rough order for recording the demo.
- ThirdPartyAssets.md and the license files: asset sources and permissions.
